6 步流程（每步都有图和对应按钮高亮）

  1. 注册并登录 GitHub（免费邮箱注册）
  2. 新建仓库 weather-diary → 选 Public → Create repository
  3. 上传全部文件（把本文件夹所有文件拖进网页 → Commit changes）
  4. 开启 GitHub Pages：Settings → Pages → Source 选 Deploy from a branch → main /(root) → Save
  5. 拿到 https 链接：https://%E4%BD%A0%E7%9A%84%E7%94%A8%E6%88%B7%E5%90%8D.github.io/weather-diary/weather-diary.html
  6. 手机打开链接 → 添加到主屏幕：安卓 Chrome 点「安装应用」，iPhone Safari 用「添加到主屏幕」

操作要点

  • 一定要上传全部文件（html + sw.js + manifest + 图标），否则装不上。
  • 仓库必须选 Public 才能用免费 Pages。
  • Pages 设置保存后等 1–2 分钟，绿字出现才是发布成功。
  • 手机上必须用浏览器打开那个 https 链接，不能直接打开 html 文件。

双击打开 deploy-guide.html 就能跟着图片一步步操作，不需要会写代码或 git。

原因找到了，也给你两路解法。

为什么拖不进去
GitHub 的上传框只接收「文件」，不接收「文件夹」。你直接把整个 weather-diary 文件夹拖进去，它不会报错也不会反应——这是 GitHub 的已知限制，不是你操作错了。

解法一：GitHub 也能传（但要选对）
进到 weather-diary 文件夹里 → 选中里面全部文件（weather-diary.html、sw.js、manifest.webmanifest、icon-192.png、icon-512.png、icon.svg）→ 再把这些文件一起拖进上传框。注意是"里面的文件"，不是"文件夹"。

解法二（最省事，推荐你用）：Netlify 直接拖整个文件夹
Netlify 的拖拽部署页支持整文件夹，正好避开你这个坑：

  1. 打开 app.netlify.com/drop（连账号都不用登）
  2. 把整个 weather-diary 文件夹拖进虚线框
  3. 几秒后自动上线，页面直接给出 https://xxx.netlify.app 链接
  4. 手机打开该链接 → 加到主屏幕
